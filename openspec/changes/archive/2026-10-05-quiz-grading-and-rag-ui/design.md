## Context

Дамп Stepik не содержит вариантов/ключей тестов — `block.options` хранит только `is_multiple_choice`; ключи отдаёт `/api/step-sources` (нужен доступ автора курса). RAG-ассистент нужно встроить в страницу шага.

## Goals / Non-Goals

- Goals: авто-проверка тестов при наличии ключа; безопасный показ шага; чат-панель в web.
- Non-Goals: ручная проверка преподавателем, парсинг всех экзотических типов Stepik.

## Decisions

- **`step_sources.payload` — сырой `block`** из Stepik; `domain/quiz.py` разбирает ключ гибко (choices/answer в разных контейнерах). Типы авто-проверки: choice/number/string.
- **Отсутствие ключа → manual**: UI не показывает варианты, студент отмечает выполнение. Это осознанный компромисс при недоступном токене.
- **`get_answer_key`** — отдельный метод порта, чтобы не отдавать ключ в `StepDetail`.
- **Чат-панель** создаёт сессию с `course_id`; пользователь выводится из сессии студента в API.
- **Миграция `0005`**: создаёт `step_sources` и unique index `(user_id, step_id)` для upsert прогресса.

## Risks / Trade-offs

- Токен текущего окружения не имеет доступа к step-sources → тесты курсов остаются manual до подключения токена автора.
- Тело шага рендерится как доверенный HTML (`|safe`); источник — импорт Stepik.
