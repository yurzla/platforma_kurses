## Context

Блок «Источники:» был обязателен всегда; при исчерпанном списке курсов модель отвечает фиксированной
фразой и источников у ответа нет. В промпте нужно явно оговорить это единственное исключение.

## Goals / Non-Goals

- Goals: блок «Источники:» всегда, кроме ответа «Больше подходящих курсов в списке нет.».
- Non-Goals: изменения кода/sanitize, гарантия исполнения моделью.

## Decisions

### Исключение в правиле 7
Правило 7: блок обязателен в каждом ответе; единственное исключение — ответ ровно фразой
«Больше подходящих курсов в списке нет.». Правка только в промпте.

## Risks / Trade-offs

- [Нет гарантии] GigaChat может не соблюсти инструкцию; кодовый гард не добавляется (prompt-only).

## Migration Plan

Без миграций. Меняется только текст промпта для новых ответов.
