## Context

См. `proposal.md`. `GET /api/v1/courses` (`catalog.py::list_courses`) возвращает `CourseSummaryRead` со всеми опубликованными курсами и полями `enrolled`/`progress_percent`, которые вычисляются в `SqlCatalogRepository.list_courses` через outer join на `enrollments` текущего пользователя. Web-сервис уже рендерит карточки курсов в `templates/courses.html` и передаёт cookie через `call_api` с поддержкой `params`.

## Goals / Non-Goals

**Goals:**
- Отдельная страница «Мои курсы» на web-слое поверх API-фильтра.
- Фильтрация на уровне SQL, единый контракт для других клиентов.
- Переиспользование разметки карточек курсов.

**Non-Goals:**
- Изменение схемы БД или модели `CourseSummaryRead`.
- Автоматическая запись на курс при открытии (enrollment создаётся при первом результате шага).
- Отдельный раздел «завершённые»: начатые и завершённые показываются вместе.

## Decisions

- **Фильтр в API `enrolled=true`**, а не на web-слое: каталог — источник истины, фильтр выполняется в SQL (`WHERE EnrollmentORM.progress_percent IS NOT NULL`), не тратит трафик. Альтернатива (фильтровать список в `pages.py`) отклонена как менее чистая.
- **`enrolled_only` — keyword-only параметр порта** `list_courses(user_id, *, enrolled_only=False)`, чтобы не ломать существующие вызовы; значение по умолчанию сохраняет прежнее поведение.
- **`enrolled` = наличие записи enrollment**, что совпадает с текущей семантикой поля `enrolled` в ответе; автозаписи при открытии курса нет.
- **Общий шаблон карточек** `_course_cards.html` (сетка карточек + пустое состояние через `empty_text`), включается в `courses.html` и `my_courses.html`.
- **Вкладка «Мои курсы»** в `_topbar.html` после «Курсы» только для `me.role`.

## Risks / Trade-offs

- [Страница пуста, пока пользователь не ответил ни на один шаг] → принято («уже начатые»); в пустом состоянии есть ссылка на каталог.
- [Фейк раньше помечал все курсы как enrolled] → приводим фейк к семантике репозитория (enrollment по прогрессу), заодно считаем прогресс по курсу, а не по всем сразу.
- [Дублирование разметки карточек] → снимается общим include.
