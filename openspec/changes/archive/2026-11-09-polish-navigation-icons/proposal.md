# Proposal

## Why

В шапке рядом с названием остался текст «· обучение», кнопка ассистента
занимает место надписью, а кнопка поиска — текстом «Найти». Ссылки-кнопки
«Назад/Вперёд» и «Сбросить» выглядят как подчёркнутые ссылки, что ломает
единый стиль кнопок.

## What Changes

- Подключаются Bootstrap Icons (локально, без CDN в рантайме).
- В шапке удаляется «· обучение», рядом с названием добавляется иконка робота.
- Кнопка вызова ассистента показывает иконку робота вместо надписи и сохраняет
  доступное имя.
- Кнопка поиска показывает только иконку поиска и сохраняет доступное имя.
- Базовый класс `.btn` больше не подчёркивает текст, поэтому ссылки-кнопки
  «Назад/Вперёд» и «Сбросить» выглядят как обычные кнопки.

## Capabilities

### Modified Capabilities

- `web-interface`: уточняется оформление шапки и иконочных кнопок.

## Impact

- Web: `base.html`, `_topbar.html`, `_list_search.html`, `dashboard.css`,
  `web.css`, новые файлы `static/vendor/bootstrap-icons/*`.
- Тесты: `tests/web/test_web.py`.
- Backend, API и БД не меняются.
