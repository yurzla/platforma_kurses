# Proposal

## Why

После сохранения, создания или удаления шага преподаватель попадает на битый
адрес: форма шага отправляет пустой `course_id`, потому что частичный шаблон
`_step_form.html` использует переменную `course_id`, которой нет в контексте
страницы курса.

## What Changes

- Скрытое поле формы шага берёт идентификатор курса из уже доступного объекта
  `course` (`course.id`) вместо неопределённой переменной `course_id`.
- Добавляется регрессионная проверка, что отрендеренная форма содержит реальный
  идентификатор курса.

## Capabilities

### Modified Capabilities

- `web-interface`: уточняется, что после сохранения шага пользователь
  возвращается на страницу редактируемого курса.

## Impact

- Web: `web/src/courses_web/templates/_step_form.html`.
- Тесты: `tests/web/test_web.py`.
- Backend, БД и API не меняются.
