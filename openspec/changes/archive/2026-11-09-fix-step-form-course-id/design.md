# Design

## Context

`_step_form.html` — общий partial для создания и редактирования шага. В нём
есть скрытое поле `course_id`, которое обработчики web читают для редиректа
обратно на `/teacher/courses/{course_id}`. Partial включается из
`teacher_course.html`, где в контексте есть `course`, но нет `course_id`.

## Goals / Non-Goals

**Goals:**

- Возврат на страницу курса после создания, сохранения и удаления шага.

**Non-Goals:**

- Не меняем API и обработчики — они уже корректно используют `course_id` из
  формы.

## Decisions

1. **Использовать `course.id` в partial.** Объект `course` уже передаётся и в
   форму создания, и в форму редактирования, поэтому дополнительная переменная
   контекста не нужна.

## Risks / Trade-offs

- [Дублирование источника course id] → `course.id` — тот же объект, что и
  используется остальными формами страницы (`section`, `lesson`).

## Migration Plan

Не требуется.
