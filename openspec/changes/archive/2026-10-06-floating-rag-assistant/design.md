## Context

См. proposal.md. Текущий чат-виджет живёт инлайном в `templates/step.html` и инициализируется в `static/web.js` только при наличии `#chat-form`. `templates/base.html` — общий каркас; родительские шаблоны передают `me` (на login/register `role = None`). `routers/pages.py` отдаёт `course_id` в контекст только для страницы курса и шага. API чата (`POST /api/v1/chat/sessions`, `POST .../ask`, `GET /api/v1/jobs/{id}`) остаётся без изменений и доступен через web-прокси.

## Goals / Non-Goals

**Goals:**
- Один переиспользуемый виджет ассистента в общем каркасе, включаемый только на страницах обучения (курс и шаг).
- Панель справа поверх страницы (drawer) без сдвига контента и с независимым от страницы состоянием диалога.

**Non-Goals:**
- История чата между перезагрузками страниц (in-memory на время загрузки).
- Изменения backend/API и схемы БД.
- Мобильная адаптация сверх базовой ширины drawer.
- Ассистент на списке курсов, админ-панели и страницах входа/регистрации.

## Decisions

- **Размещение виджета в `base.html` под `{% if me and me.role and course_id %}`** — единая точка рендера, включается только там, где родительский роутер передал `course_id` (страница курса и шаг). Так автоматически исключаются дашборд, `/courses`, login/register. Альтернатива (флаг `show_assistant`) требует править каждый роутер.
- **Контекст курса через data-атрибут виджета** (`data-course-id="{{ course_id }}"`), а не глобал `window.COURSE_ID`. `course_id` добавляется в контекст `course()` в `pages.py`; в `step()` уже есть. `window.COURSE_ID` сохраняется для формы ответа на шаг.
- **Без выбора курса**: виджет рендерится только там, где `course_id` известен, поэтому `ensureSession` использует его напрямую; селектор курса и запрос `GET /api/v1/courses` из виджета убраны.
- **Переиспользование существующего потока session → ask(202) → poll**: логика из `web.js` выносится в generic-init; убирается отправка `user_id` (API привязывает сессию к текущему пользователю и игнорирует поле).
- **CSS**: FAB `fixed; left/bottom: 20px; z-index: 60`; drawer `fixed; top:0; right:0; height:100%; width:min(420px,100vw); transform:translateX(100%)` → `.open { transform:none }`, `z-index: 61`. Цвета — существующие CSS-переменные (тема light/dark).
- **Сохранение диалога при закрытии** — панель только скрывается (`transform`), DOM и `sessionId` не сбрасываются.

## Risks / Trade-offs

- [z-index конфликты с дашбордом] → виджет на дашборде больше не рендерится, конфликт снят.
- [Состояние диалога теряется при навигации] → осознанное упрощение (Non-Goals).
- [Тесты фронтенда отсутствуют] → проверяем серверный рендер (наличие/отсутствие виджета по страницам) в `tests/web/test_web.py`.
