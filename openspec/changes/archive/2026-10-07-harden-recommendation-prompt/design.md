## Context

На просьбу «ещё курсы» модель добавляла курсы вне переданного раздела «РЕКОМЕНДУЕМЫЕ КУРСЫ»;
`sanitize_course_recommendations` их удалял (allowed = матчи текущего запроса), оставляя пустой
список и висячий `Источники:`. Гарантировать поведение кодом не стали — выбран prompt-only подход.

## Goals / Non-Goals

- Goals: модель рекомендует только курсы из раздела «РЕКОМЕНДУЕМЫЕ КУРСЫ»; при исчерпанном списке
  честно говорит, что других подходящих курсов нет.
- Non-Goals: изменение `sanitize_course_recommendations`/handlers, детерминированный фолбэк,
  расширение allowed до каталога.

## Decisions

### Ужесточение правила 6 в SYSTEM_PROMPT
Явные пункты: рекомендовать ТОЛЬКО из раздела «РЕКОМЕНДУЕМЫЕ КУРСЫ»; не добавлять курсы из истории,
материалов урока и своих знаний; на «ещё/другие» при исчерпанном разделе — сказать, что других
подходящих курсов нет, и не выдумывать; при отсутствии/пустоте раздела — не перечислять курсы.
Изменение только в промпте.

## Risks / Trade-offs

- [Нет гарантии] Модель может всё равно нарушить инструкцию; тогда sanitize по-прежнему срежет
  «левые» курсы и ответ может опустеть. Принято осознанно (prompt-only, без фолбэка).

## Migration Plan

Без миграций. Меняется только текст промпта для новых ответов.
