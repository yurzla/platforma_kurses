## Context

Ответы и пункты списков идут подряд; для читаемости нужен пустой строкой разделитель между
блоками и между пунктами.

## Goals / Non-Goals

- Goals: пустая строка между смысловыми блоками и между пунктами списков.
- Non-Goals: изменения кода/sanitize; гарантия исполнения моделью.

## Decisions

### Правило 9 в SYSTEM_PROMPT
Новое правило: отделять смысловые блоки ответа пустой строкой; пункты списков — тоже пустой строкой.
Правка только в промпте.

## Risks / Trade-offs

- [Нет гарантии] GigaChat может не соблюсти форматирование; кодовый пост-обработчик не добавляется.

## Migration Plan

Без миграций. Меняется только текст промпта для новых ответов.
