# Proposal

## Why

На подвкладке «Чанки» выбранное в фильтре «Курс» значение сбрасывается через
несколько секунд. Фоновое обновление раз в 5 секунд вызывает
`loadChunksTab()` → `loadIndex()`, а `renderIndex()` каждый раз заново собирает
опции `#ch-course` и выставляет значение из `state.chunks.course_id`, которое
меняется только по кнопке «Применить». В итоге ручной выбор теряется.

## What Changes

- Пересобирать опции селекта «Курс» только при изменении списка курсов.
- Сохранять текущее выбранное значение при пересборке опций.
- Не сбрасывать выбор, пока пользователь не нажал «Применить» или «Сброс».
- Сравнивать идентификаторы курсов как строки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `ops-dashboard`: выбранное значение фильтра «Курс» должно переживать фоновое
  обновление сводки индекса.
