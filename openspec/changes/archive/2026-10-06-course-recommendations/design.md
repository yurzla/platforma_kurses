## Context

`process_question` формирует ответ только по чанкам материалов (`CourseChunkRepository.search` →
`build_context`). Каталог курсов доступен через `CatalogRepository.list_courses(user_id, ...)`,
но в промпт не попадает. Для глобальных сессий (`course_id is None`) материалы ищутся по всем
курсам, поэтому там уместно и рекомендовать курсы. На курсовых сессиях материалы и ответы
ограничены курсом.

## Goals / Non-Goals

**Goals:**
- В глобальных чатах ассистент рекомендует курсы из каталога платформы (без выдумывания).
- Учитывать записанные курсы пометкой «вы записаны».
- Отвечать по каталогу, когда по вопросу не нашлось материалов, но каталог есть.

**Non-Goals:**
- Семантический поиск по описаниям курсов (каталог маленький, вкладываем целиком).
- Ссылки/переходы на курсы в UI, цитирование курсов как источников.
- Изменение поведения курсовых сессий.

## Decisions

- Каталог подмешивается в системный промпт только при `session.course_id is None`. Альтернатива
  (всегда) отклонена: на курсовой странице ответ ограничен текущим курсом.
- Каталог формируется как текст (`build_course_catalog`) из `CourseSummary` (название, описание
  до 300 символов, пометка «(вы записаны)»). Альтернатива с эмбеддингами отклонена из-за
  небольшого числа курсов и лишней инфраструктуры.
- Ветка «нет чанков»: если каталог пуст — прежний `NO_MATERIALS_ANSWER` без LLM; если каталог
  есть — вызов LLM с пустыми материалами. Это нужно для вопросов-рекомендаций.
- `sources` по-прежнему только чанки; рекомендованные курсы источниками не помечаются.
- Лимит каталога — настройка `catalog_prompt_limit` (по умолчанию 50).

## Risks / Trade-offs

- Промпт глобальных сессий удлиняется (~несколько тысяч символов) — приемлемо для 17 курсов.
- LLM может упомянуть курс, близкий по теме, но с неточной формулировкой; правило «только из
  каталога» снижает риск, но не исключает полностью.
- При пустых материалах и непустом каталоге модель может отвечать не по теме вопроса — правило
  «если материалов недостаточно, скажи об этом» остаётся в промпте.
