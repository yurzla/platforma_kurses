## Context

В course-сессии каталог курсов в промпт не попадает, но в материалы каждого чанка входит заголовок «Курс: «Название» (/courses/ID)» (`domain/context.py`). Из-за этого модель может предлагать пройти текущий курс.

## Goals / Non-Goals

- Goals: ассистент внутри курса не предлагает пройти этот же курс; ответы по материалам и секция «Источники» сохраняются.
- Non-Goals: запрет рекомендаций других курсов внутри курса (каталог и так не передаётся); детерминированная вырезка фраз.

## Decisions

### Промптовый запрет, без пост-фильтра
Добавляем в системный промпт отдельную секцию «ТЕКУЩИЙ КУРС СТУДЕНТА» с названием/ссылкой текущего курса и явным запретом предлагать его пройти/записаться/выбрать. Детерминированно вырезать такую прозу отвергнуто: высок риск задеть легитимный текст («в этом курсе вы освоите…»).

### Источник названия текущего курса
Название берётся из первого полученного чанка с `course_id == session.course_id` (поиск ограничен курсом), fallback — «Курс». Доп. запрос к БД не нужен.

### Прокидка параметра
`current_course: tuple[int, str | None] | None` проходит через `generate_answer` → `build_answer_messages` → `build_answer_system_prompt`. Для глобальных сессий `None`, секция не добавляется.

## Risks / Trade-offs

- [Надёжность] Промпт не даёт 100% гарантии; при повторном проявлении можно добавить пост-фильтр отдельным изменением.

## Migration Plan

Без миграций. Меняется только промпт для новых ответов.
