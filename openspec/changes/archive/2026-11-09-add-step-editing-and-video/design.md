# Design

## Context

См. `proposal.md`. Шаги хранятся в `steps` + `step_contents` (HTML-тело) +
`step_choice_options`/`choice_question_metadata` (тесты) + `step_sources`
(ответы string/number). Страница преподавателя показывает шаги только текстом и
умеет лишь создавать их. Существующие видео вставлены как `<iframe>` прямо в
HTML-тело шага и рендерятся через `| safe`.

## Goals / Non-Goals

**Goals:**

- Редактирование и удаление шага без пересоздания урока.
- Единое необязательное поле видео-ссылки для всех типов шагов.
- Обратная совместимость с уже сохранёнными iframe-видео.
- Читаемая форма шага и подсказка по форматированию.

**Non-Goals:**

- Не переводим содержимое шагов на Markdown — остаётся HTML.
- Не меняем импорт Stepik и существующий контент.
- Не добавляем загрузку видеофайлов — только ссылки.

## Decisions

1. **Отдельный nullable-столбец `steps.video_url`.** Видео не парсится обратно из
   HTML и не смешивается с телом. Существующие iframe в `body` остаются как есть,
   новый рендер добавляется отдельным блоком.
2. **Нормализация ссылки на сервере.** `domain/video.py` возвращает структуру
   `VideoEmbed(kind, src)`: `iframe` для YouTube/VK Video, `file` для прямых
   `.mp4/.webm/.ogg`, `link` для прочих http(s). Небезопасные схемы отклоняются.
3. **Видео доступно любому типу шага.** Поле необязательное; для `video`-шага
   дополнительно можно оставить тело пустым, если есть ссылка.
4. **Инлайн-редактирование.** На странице курса каждый шаг — карточка с
   `<details>` «Редактировать» и предзаполненной формой. Отдельных страниц нет.
5. **Общий partial формы.** `_step_form.html` используется и для создания, и для
   редактирования; различаются только `action`, подписи и наличие id шага.
6. **Смена типа шага очищает неактуальные данные.** При переходе между
   `choice` / `string|number` / остальными удаляются опции, метаданные и
   `step_sources`, затем создаются нужные.
7. **Удаление перенумеровывает шаги урока** подряд с 1 (сохраняется инвариант
   последовательной нумерации).

## Risks / Trade-offs

- [XSS через `video_url`] → схема проверяется (только http/https), URL
  экранируется в шаблоне; тело шага, как и раньше, доверенный HTML преподавателя.
- [Незнакомый видеохост не встраивается] → фолбэк обычной ссылкой, а не битый
  iframe.
- [Ошибки при смене типа шага] → удаление и создание связанных строк выполняется
  в одной транзакции.

## Migration Plan

`0009_step_video_url`: `ALTER TABLE steps ADD COLUMN video_url TEXT NULL`.
Откат — `DROP COLUMN`. Существующие данные не затрагиваются.
