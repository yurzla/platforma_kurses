## Why

Секция «Источники» сейчас перечисляет все курсы найденных материалов, включая те, о которых в
ответе ничего не сказано (например, курс попал в ретрив по совпадению, но в рекомендациях его
нет). Из-за этого студент видит в источниках курс, которого нет в тексте. Нужно, чтобы в
«Источниках» были только курсы, которые ответ реально называет.

## What Changes

- В «Источники» попадают только курсы-источники, **упомянутые в тексте ответа** — по названию
  курса или по Markdown-ссылке `[..](/courses/ID)`.
- Для чата по конкретному курсу текущий курс включается в «Источники» всегда (его материалы —
  контекст ответа), даже если название не упомянуто.
- Если после фильтрации список пуст, секция «Источники» не добавляется.
