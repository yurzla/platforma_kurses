# Proposal

## Why

Подсказка в форме шага предлагает писать HTML-теги, хотя преподавателю нужен
обычный Markdown. Сейчас тело шага выводится как сырой HTML, поэтому простой
текст с разметкой Markdown (`**жирный**`, списки, ссылки) отображается
буквально, а переносы строк не сохраняются.

## What Changes

- Тело шага интерпретируется как Markdown (CommonMark) с сохранением одиночных
  переносов строк.
- Унаследованный HTML из импортированных шагов продолжает отображаться без
  изменений.
- Подсказка по форматированию переписывается под Markdown вместо списка
  HTML-тегов.
- Видео по-прежнему добавляется через отдельное поле «Видео-ссылка».

## Capabilities

### Modified Capabilities

- `learning-catalog`: тело шага рендерится как Markdown с совместимостью со
  старым HTML.
- `web-interface`: подсказка формы описывает Markdown.

## Impact

- Web: `web/pyproject.toml`, `web/src/courses_web/markdown.py` (новый),
  `web/src/courses_web/templating.py`, шаблоны `step.html` и `_step_form.html`.
- Тесты: новый юнит-тест рендерера, правки `tests/web/test_web.py`.
- Backend, API, БД и миграции не меняются.
