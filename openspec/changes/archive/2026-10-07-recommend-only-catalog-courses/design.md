## Context

См. `proposal.md — Why`. Наблюдаемый кейс: глобальная сессия, запрос «курсы по js», чанк из
материала урока содержит анонс внешнего курса; модель подаёт его как курс портала. Уже есть
`build_course_catalog` (каталог в промпте) и `ensure_course_link` (дописывает ссылки на реальные
курсы), но они не удаляют вымышленные названия из сгенерированного текста.

## Goals / Non-Goals

**Goals:**
- Гарантировать, что в ответе нет рекомендаций и ссылок на курсы, которых нет в БД.
- Не ломать легитимный текст ответа.

**Non-Goals:**
- Переписывание/перегенерация ответа моделью.
- Изменение формата хранения и публичного API.
- Фильтрация cross-promo на этапе импорта Stepik (отдельная задача).

## Decisions

- **Детерминированный фильтр в domain.** Чистая функция
  `sanitize_course_recommendations(answer, allowed_courses)` в `domain/recommendations.py`.
  Альтернатива (только промпт) отклонена: промпт уже был и не сработал.
- **Разрешённое множество курсов**: титулы каталога (глобальная сессия) ∪ курсы-источники
  найденных чанков ∪ курс сессии. Это реальные опубликованные курсы портала.
- **Правила фильтра** (по порядку): (1) Markdown-ссылки `[label](/courses/ID)` с неразрешённым
  `ID` → заменяются на текст `label`; (2) пункт списка (строка `-`/`*`/`N.`/`N)`) и его вложенные
  подпункты удаляются, если содержат кавычечное название курса (`«...»`/`"..."`), которого нет в
  разрешённом множестве; (3) проза вне списков не изменяется — минимальный риск ложных срабатываний.
- **Кавычки**: поддерживаем `«»`, `""`, `“”`; нормализация титулов — casefold, схлопывание
  пробелов, унификация кавычек.
- **Порядок применения**: `generate_answer` → `sanitize_course_recommendations` →
  `ensure_course_link`. Сначала убираем невалидное, потом добавляем ссылки на валидное.
- **Перенумерация** оставшихся пунктов не делается (минимальные изменения текста).

## Risks / Trade-offs

- [Ложное удаление легитимного пункта списка с кавычками не про курс] → фильтруем только элементы
  списка с кавычечным названием; покрываем тестами; при частых ложных срабатываниях сузим эвристику.
- [Название курса в прозе остаётся] → осознанное ограничение; требования про ссылки и так
  гарантируют отсутствие невалидных ссылок.
- [Нормализация не совпала (регистр/пунктуация)] → сравнение по нормализованным титулам +
  сравнение по подстроке названия.
