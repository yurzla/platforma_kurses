## Why

На запрос «курсы по js» ассистент порекомендовал курс «Практический мини-курс по JavaScript и
Bootstrap 5», которого нет на платформе. Причина: название курса встречается внутри материала
урока (cross-promo в импортированном Stepik-контенте), и модель подала его из блока `МАТЕРИАЛЫ
КУРСА` как доступный курс портала. Промпт это уже запрещал, но не гарантирует результат — нужна
детерминированная проверка.

## What Changes

- Рекомендовать можно только курсы из «КАТАЛОГ КУРСОВ ПЛАТФОРМЫ» (из БД); названия курсов,
  встречающиеся внутри материалов уроков, не считаются курсами платформы.
- Backend детерминированно фильтрует ответ: удаляет пункты списка-рекомендации с названием курса,
  которого нет в базе, и разворачивает Markdown-ссылки на несуществующие курсы в обычный текст.
- Фильтр применяется до гарантированного дописывания ссылок на реальные курсы.
- Упоминания курсов в прозе (вне списков) не изменяются, чтобы не ломать цитаты материалов.

## Impact

- Backend domain: новый `domain/recommendations.py` (`sanitize_course_recommendations`).
- Backend application: `application/handlers.py` — вызов фильтра перед `ensure_course_link`.
- Промпт `domain/prompts.py`: уточнение про недопустимость рекомендаций из материалов урока.
- Тесты: новый `tests/unit/test_recommendations.py`, дополнение `test_handlers.py`.
- Схема БД и публичный API не меняются.
