## Context

См. `proposal.md — Why`. Эксперименты на реальных данных показали: (а) промпт-инженерия не заставляет
модель перечислять все подходящие курсы и провоцирует выдуманные названия; (б) прямое ранжирование
по эмбеддингам `course_description` шумное (Python/Go-курсы оказываются выше профильных);
(в) расширение запроса ключевыми словами через LLM перед эмбеддингом даёт корректный топ
(для «js» — курсы 6, 9, 3, 10; для «фронтенду» — 9, 10, 6).

## Goals / Non-Goals

**Goals:**
- Рекомендации строятся на эмбеддингах, а не на свободной генерации.
- Полный список подходящих опубликованных курсов без выдуманных названий.
- Работа на текущей модели `nomic-embed-text` без смены размерности.

**Non-Goals:**
- Смена embedding-модели и миграции векторной размерности.
- Персонализация по `user_learning_preferences`/wishlist (порт оставляет возможность).
- Изменение поиска RAG-контекста (по-прежнему `theory`/`task`, `retrieval_top_k`).

## Decisions

- **Источник вектора курса** — существующие чанки `content_chunks.source_type='course_description'`
  + `chunk_embeddings`; новых таблиц нет. Несколько чанков на курс агрегируются `MIN(distance)`.
- **Расширение запроса** — обязательный шаг: `build_recommendation_expansion_prompt` + LLM
  (`temperature=0`); в эмбеддинг идёт `question + expansion`.
- **Отбор** — чистая функция `select_courses(matches, top_k, margin, min_score)`:
  `score >= max(min_score, best - margin)`, не больше `top_k`.
- **Вывод** — детерминированный `render_recommendations` (LLM список не сочиняет).
- **Интеграция** — в `process_question`: глобальная сессия + `looks_like_course_query(question)` +
  непустые матчи → детерминированный ответ; иначе прежний RAG-путь.
- **Санитайзер** — пункт со ссылкой на валидный курс, но кавычечным заголовком-не-курсом, теперь
  удаляется (проверка по тексту ссылки).

## Risks / Trade-offs

- [nomic слабо разделяет темы] → качество держится на расширении запроса; для нерелевантных тем
  ближайшие курсы всё равно вернутся (эмбеддинги не дают «нет совпадений»). Митигация: `margin/top_k/min_score`.
- [Лишний LLM-вызов] → только для вопросов про курсы.
- [Устаревание описаний] → `embed_chunks` теперь пере-эмбеддит при изменении текста.
- [HNSW + фильтр `source_type`] → на 17 курсах несущественно.
