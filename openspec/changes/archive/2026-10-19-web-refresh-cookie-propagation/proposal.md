## Why

Если access-токен истёк, первый вызов API из обработчика страницы обновляет токен, но второй
вызов в том же запросе снова отправляет старый cookie. В результате, например, страница шага
получает шаг, но не получает структуру курса: пропадают навигация и прогресс-бар («0 из 0»).

## What Changes

- `call_api` использует cookie, обновлённые авто-refresh-ем, для всех последующих вызовов API в
  рамках одного HTTP-запроса к web.
- Тест: страница шага при испорченном access-токене после refresh рендерит и шаг, и структуру
  курса (прогресс и соседей).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `web-interface`: авто-refresh access-токена распространяется на все API-вызовы одного запроса.

## Impact

- Web: `client.py` (сборка заголовков `call_api`), тест в `tests/web`.
- API/БД не меняются; пересборка образа `web`.
