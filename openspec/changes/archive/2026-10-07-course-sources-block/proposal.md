## Why

Служебный блок ответа ассистента подписан «Подробнее» и смешивает источники материала с
рекомендованными курсами, что непонятно студенту. Нужен явный список источников: секция
«Источники» со всеми курсами, чьи материалы были использованы в ответе.

## What Changes

- Backend вместо блока «Подробнее» добавляет в конец ответа секцию **«Источники:»** со ссылками
  на **все** курсы-источники (уникальные курсы найденных чанков).
- Секция всегда перечисляет все курсы-источники, даже если ссылка на курс уже есть в тексте
  ответа; при отсутствии материалов секция не добавляется.
- Убирается детерминированное дописывание ссылок на рекомендованные курсы: ссылки на
  рекомендации модель формирует в тексте ответа по инструкции промпта.
- Убирается неиспользуемый после этого метод каталога `get_course_summary`.

## Impact

- Backend domain: `domain/prompts.py` (`build_sources_section` вместо `ensure_course_link`).
- Backend application: `application/handlers.py` (сбор курсов-источников, добавление секции).
- Backend ports/adapters: удаление `get_course_summary` из `application/ports.py`,
  `adapters/persistence/repositories.py`, `tests/fakes.py`.
- Тесты: `tests/unit/test_domain.py`, `tests/unit/test_handlers.py`, `tests/api/test_api.py`.
- Схема БД и публичный API не меняются.
