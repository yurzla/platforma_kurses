## Context

Ответ и секция «Источники» собирались детерминированно в `handlers.py` (`build_sources_section`,
`render_recommendations`) поверх текста модели, а в промпт ответа подмешивался каталог курсов.
Из-за этого текст ответа и блок «Источники» могли расходиться, а модель опиралась на каталог, а не
на материалы курса.

## Goals / Non-Goals

- Goals: ответ и блок «Источники» формирует LLM; grounding строго по переданным чанкам (и секции
  рекомендованных курсов для вопросов о подборе); каталог в промпте ответа отсутствует.
- Non-Goals: изменение набора рекомендаций и эмбеддингов; гарантия полноты «Источников»;
  детерминированный пост-фильтр текста ответа.

## Decisions

### Источники формирует модель
В `SYSTEM_PROMPT` добавлено правило завершать ответ блоком «Источники» со ссылками на курсы
переданных источников, брать названия/URL только из данных и не придумывать. Бэкенд больше не
дописывает секцию: `build_sources_section` и `CATALOG_DESCRIPTION_LIMIT` удалены. Полнота списка
не гарантируется — принято сознательно (доверяем LLM).

### Только чанки, каталог убран
`build_answer_system_prompt(context, current_course, recommended_courses)` больше не принимает
`catalog`; в промпте остаются только секции «МАТЕРИАЛЫ КУРСА» и «РЕКОМЕНДУЕМЫЕ КУРСЫ». Ветка
«ответ по каталогу без чанков» удалена: при отсутствии чанков (и отсутствии рекомендаций) сразу
возвращается `NO_MATERIALS_ANSWER` без вызова LLM. `catalog_prompt_limit` удалён из `Settings`.

### Рекомендательная ветка через LLM
`domain/recommender.py`: `render_recommendations` заменён на
`build_recommended_courses_section(matches, description_limit)` — компактный список
`- [«Title»](/courses/ID) — описание` для секции «РЕКОМЕНДУЕМЫЕ КУРСЫ». `handlers` передаёт секцию
в `generate_answer(recommended_courses=...)` и берёт текст модели; `sanitize_course_recommendations`
по-прежнему срезает ссылки на курсы, которых нет среди рекомендованных.

### Метка фрагментов `[Источник i]`
`domain/context.py` вернулся к `[Источник i]`: LLM теперь сама пишет «Источники», а метка не должна
провоцировать дублирование заголовка.

## Risks / Trade-offs

- [Полнота] Модель может перечислить не все источники или опустить блок. Принято: grounding важнее
  детерминированной полноты.
- [Рекомендации] Список рекомендаций теперь генерируется и может отличаться формулировкой от
  кандидатов; ссылки на нерекомендованные курсы срезаются.

## Migration Plan

Без миграций БД. Меняется только поведение вновь генерируемых ответов.
