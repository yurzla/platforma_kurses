# Design

## Backend

`index_summary` перестаёт строить список курсов из агрегата `content_chunks`.
Вместо этого:

1. Загружаются все курсы: `select(CourseORM.id, CourseORM.title)`.
2. Агрегаты чанков по курсам и эмбеддингов по курсам остаются отдельными
   запросами.
3. Для каждого курса счётчики подставляются из словарей, отсутствующие значения
   равны нулю.

Статус курса:

- `empty` — `chunks == 0`;
- `missing_embeddings` — `chunks > 0` и `embeddings == 0`;
- `partial` — `embeddings < chunks`;
- `ok` — иначе.

Сводка дополняется `courses_without_embeddings` и `courses_without_chunks`.
Сортировка: сначала проблемные статусы (`empty`, `missing_embeddings`,
`partial`), затем `ok`; внутри статуса — по убыванию числа чанков и id.

## Web

- Вкладка «Индекс» использует вертикальный контейнер `.index-stack`; вкладка
  «Состояние» продолжает использовать двухколоночный `.index-columns`.
- Карточки: «чанков», «эмбеддингов», «чанков без эмбеддинга», «курсов без
  эмбеддингов», «курсов без чанков».
- В таблице по курсам добавляется колонка «Состояние» с бейджем:
  `нет чанков`, `нет эмбеддингов`, `частично`, `ок`.

## Testing

- Интеграционный тест создаёт курс с чанками и частичными эмбеддингами и
  отдельный курс без чанков; проверяет статусы, счётчики и наличие пустого курса
  в сводке.
- Web-тест проверяет вертикальный контейнер, новые карточки и колонку статуса.
