# Design

## Context

См. `proposal.md`. Ошибки находятся в коде, добавленном текущей веткой до
восстановления фич. Они не связаны с логикой шагов и чатов.

## Goals / Non-Goals

**Goals:**

- Сделать `ruff check .` и `mypy` зелёными без изменения поведения.
- Сохранить стиль проекта: line-length 100, импорты через `ruff`.

**Non-Goals:**

- Не менять публичные контракты API и схемы БД.
- Не рефакторить логику преподавателя или администратора сверх форматирования.

## Decisions

1. **Сначала автофиксы ruff.** `ruff check . --fix` безопасно закроет
   сортировку импортов и лишние кавычки. Остальные `E501`/`E702` правятся
   вручную, чтобы не менять структуру кода.
2. **Mypy через существующие паттерны.** В репозитории уже используется
   `cast("CursorResult[Any]", ...)` для `rowcount`; применяем тот же приём.
   В админ-роутере переименовываем ORM-переменную, не меняя бизнес-логику.
3. **Без `ruff format` целиком.** Форматируем только проблемные места, чтобы
   дифф оставался обозримым.

## Risks / Trade-offs

- [Случайно изменить поведение при разбиении длинных выражений] → После правок
  прогоняются `ruff`, `mypy` и полный `pytest`, включая интеграционные тесты.
