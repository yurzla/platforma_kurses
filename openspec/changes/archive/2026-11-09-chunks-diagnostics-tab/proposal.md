# Proposal

## Why

Таблица чанков находится внутри вкладки «Индекс» вместе со сводкой и таблицей
по курсам. Из-за этого вкладка перегружена, а фильтры и пагинация чанков
конкурируют с обзорной статистикой. Чанки — отдельный сценарий диагностики.

## What Changes

- В «Технической диагностике» добавить подвкладку «Чанки».
- Перенести фильтры, таблицу и пагинацию чанков из «Индекса» в новую подвкладку.
- Оставить на вкладке «Индекс» только карточки, разбивку по типам и таблицу по
  курсам.
- При открытии «Чанков» подгружать список курсов для фильтра, даже если «Индекс»
  не открывался.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `ops-dashboard`: просмотр чанков должен быть доступен на отдельной подвкладке,
  а сводка индекса — без таблицы чанков.
