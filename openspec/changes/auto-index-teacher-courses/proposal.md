# Автоматическая индексация курсов преподавателя

## Why

Курс, созданный или отредактированный преподавателем, сохраняется в PostgreSQL, но не попадает
в RAG-индекс до ручного запуска `embed_chunks`. Из-за этого помощник не может находить даже
описание нового курса.

## What Changes

- API ставит асинхронную задачу индексации после создания курса и после изменения его названия
  или описания.
- Выделенный indexer-консьюмер читает отдельный Redis Stream, обновляет чанк описания курса и
  его embedding через Ollama.
- Создание и сохранение учебного шага ставят задачу обновления чанков и embeddings этого шага.
- Повторная задача для неизменившегося текста не вызывает Ollama; изменённый текст заменяет
  текст чанка и его embedding.

## Non-goals

- Интерфейс статуса индексации в кабинете преподавателя.
