# Design

## Решение

Плейсхолдер создаётся отдельной функцией `appendPending()` в `web.js` вместо обычного текстового
узла:

```html
<div class="chat-msg assistant chat-pending">
  <span class="chat-spinner" aria-hidden="true"></span>
  <span class="chat-pending-text" role="status">Ассистент отвечает…</span>
</div>
```

Так иконка — декор (`aria-hidden`), а текст озвучивается как статус (`role="status"`).

## Центрирование

Обёртка `chat-pending` — `inline-flex` с `align-items: center`, поэтому иконка центрируется по
вертикали относительно строки текста независимо от высоты строки. Спиннер — круг 16×16 с рамкой
толщиной 2px, верхняя грань контрастная, вращение через `@keyframes chat-spin`.

## Совместимость с существующей логикой

Все ветки завершения (`placeholder.textContent = ...` для ошибок и таймаута, `node.textContent =
""` с последующей вставкой ответа) заменяют все дочерние узлы, поэтому спиннер исчезает
автоматически без дополнительного кода очистки.

## Доступность

`prefers-reduced-motion: reduce` замедляет вращение вместо полного отключения, чтобы индикатор
оставался заметным.
