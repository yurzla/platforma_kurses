# Предпочтения студента в «Моём обучении»

## Why

Таблица `user_learning_preferences` уже существует, но студент не может заполнить интересы,
учебные цели и желаемый уровень через продукт.

## What Changes

- Добавляется API текущего пользователя для чтения и сохранения предпочтений.
- На `/my-courses` появляется форма с интересами, целями и желаемым уровнем.
- Сохранение обновляет единственную строку предпочтений пользователя в PostgreSQL.
- Глобальные рекомендации ассистента используют сохранённые настройки как дополнительный
  контекст в embedding-запросе.

## Non-goals

- Изменение предпочтений другого пользователя администратором.
